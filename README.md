# OGC 2025 선박 차량 적재·하역 최적화

2025 OGC 공모전의 차량 운송선 적재 문제를 푸는 Python 알고리즘입니다. 선박 내부를 그래프로 표현하고, 여러 항구에서 차량을 싣고 내리는 이동 순서를 정해 고정비와 이동 거리 비용의 합을 줄입니다.

## 코드 구성

- `baseline/`: 공모전에서 제공한 베이스라인 코드. 직접 작성한 코드와 구분해 보관합니다.
- `src/`: 베이스라인에서 발전시킨 알고리즘. 경로를 고려한 차량 배치, 노드 우선순위, 클러스터 구성 및 여러 휴리스틱을 실험했습니다.
- `examples/`: 공모전에서 제공한 연습 문제 입력입니다.

진입점은 `src/myalgorithm.py`의 `algorithm(prob_info, timelimit=60)`입니다. `src/`를 Python 모듈 경로에 두고 공모전의 문제 입력과 평가 환경에서 호출합니다. `networkx`와 `numpy`가 필요합니다.

## 출처와 결과

문제 정의, 베이스라인 코드, 연습 문제 입력은 OGC 2025 주최 측이 제공했습니다. `src/`의 개선 알고리즘은 베이스라인을 바탕으로 개발했습니다. 이 저장소의 개별 결과 파일은 서로 다른 문제·제한시간의 실행 결과일 수 있으므로, 성능 비교 수치는 동일한 조건으로 재평가한 뒤 기록합니다.
